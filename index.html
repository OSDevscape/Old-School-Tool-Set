Old School Tool Set

A Discord bot built from Old School RuneScape — bringing moderation, economy, and powerful clan utilities into one lore‑friendly package.

Designed for the Bonded4Life clan
Free for Clan members & Guests to use
Backed by the Old School Wiki

What the bot can do

  • Slayer Codex - Information on Slayer tasks and their requirements.
  • Integrated Clan Ranking system
  • Utility commands powered by TempleOSRS & our own API

Getting started

  • To set your character name, use the /rsn command.
  • To view your profile, use the /profile command.
  • Use /help for a list of commands determined by your role within the Server based on your rank in the Clan.
